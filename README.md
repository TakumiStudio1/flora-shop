# FLORA — Premium Plant Shop

E-commerce design and web for a curated online plant shop. Light theme with natural green tones, serif typography, CSS-drawn plants, and rich scroll animations.

## Project

Portfolio piece #4 — e-commerce with organic aesthetic and interactive product cards.

## Stack

- HTML5 semantic
- CSS custom properties + @keyframes
- Vanilla JS (IntersectionObserver, requestAnimationFrame)
- Zero dependencies

## Structure

```
index.html          → Landing page with hero, categories, products
shop.html           → Product listing with filters and grid
assets/             → Logo, isotipo, favicon (SVG)
behance/            → 12 slides for presentation
```

## Animations

- Loader with spinning leaf and staggered letters
- Custom cursor with lerp ring + dot follower
- Floating leaf particles
- Hero word-by-word 3D reveal
- CSS plants with leaf sway animation
- Product card tilt with perspective on hover
- Quick view button slide-up on hover
- Scroll-driven card reveals with stagger
- Counter animations with cubic easing
- Marquee ticker
- Wishlist heart toggle
- Filter pill active states
- Scroll progress bar
- prefers-reduced-motion respected
